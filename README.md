# LPC1768_Projects
### In this repo I will be using an LPC1768 based microcontroller board to execute programs, and learn the fundamentals of Microcontrollers

## Components I will be using
 - Software 
    - KeiluVision4 for Development
    - Flashmagic for Flashing onto Board
 - Hardware 
    - LPC1768 based Keil MCB1700 Evaluation board
    - USB-RS232 Converter board
